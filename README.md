# 📊 Samsung Supply Chain & Logistics Dashboard (Power BI)

![Dashboard Screenshot](PASTE_YOUR_IMAGE_LINK_HERE)

## 📌 Project Overview
This project is a **Supply Chain & Logistics Dashboard** developed using **Power BI** to analyze key business operations such as suppliers, inventory, shipments, and customers.  
The dashboard helps in monitoring revenue, profit, delivery performance, inventory levels, and shipment delays.

---

## 🗂 Dataset Description
The project uses multiple CSV files designed in a star schema model.

### 🔹 Dimension Tables
- `dim_customer.csv` – Customer details  
- `dim_date.csv` – Date information  
- `dim_facility.csv` – Facility and warehouse data  
- `dim_product.csv` – Product information  
- `dim_supplier.csv` – Supplier details  

### 🔹 Fact Tables
- `fact_inventory.csv` – Inventory stock records  
- `fact_procurement.csv` – Procurement transactions  
- `fact_production.csv` – Production data  
- `fact_sales.csv` – Sales transactions  
- `fact_shipment.csv` – Shipment and delivery data
